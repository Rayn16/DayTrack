# CLAUDE.md

## Code map (Graphify)
This repo has a Graphify code map in graphify-out/.
- Before exploring the code, read graphify-out/GRAPH_REPORT.md.
- For "where is X" or "how does X reach Y" questions, run `graphify query "<question>"` before grepping or opening many files. If graphify is missing, install it with `pip install graphifyy`.
- After a change that adds, moves or deletes files, run `graphify update .` and commit the updated graphify-out/.
